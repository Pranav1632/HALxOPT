========================================================================
                     AEROOPTIMA RUN GUIDE & COMMANDS
========================================================================

This project consists of:
1. A FastAPI Python backend (Physics simulation, Genetic Algorithm optimizer, RL Agent).
2. A Next.js/React frontend dashboard (Telemetry visualization, controls, 3D orbit map).

------------------------------------------------------------------------
PREREQUISITES
------------------------------------------------------------------------
Make sure you have the following installed:
- Python 3.10+ (with pip)
- Node.js 18+ (with npm)

========================================================================
1. BACKEND SETUP & RUN
========================================================================
Navigate to the backend directory first:
> cd backend

--- Create Virtual Environment ---
Windows (PowerShell):
> python -m venv .venv

--- Activate Virtual Environment ---
Windows (PowerShell):
> .\.venv\Scripts\Activate.ps1

Windows (CMD):
> .\.venv\Scripts\activate.bat

macOS / Linux:
> source .venv/bin/activate

--- Install Dependencies ---
> pip install -r requirements.txt

--- Run the Backend Server ---
> python main.py
* Serves the API at: http://127.0.0.1:8000
* Swagger Docs: http://127.0.0.1:8000/docs

--- Running Tests & Diagnostics ---
Run diagnostic/simulation CLI logs in active venv:
> python test_env.py

Run the full 6-scenario multi-condition test suite:
> python test_all_conditions.py

========================================================================
2. FRONTEND SETUP & RUN
========================================================================
Navigate to the frontend directory first:
> cd frontend

--- Install Dependencies ---
> npm install

--- Run the Development Server ---
> npm run dev
* Serves the web interface at: http://localhost:3000

========================================================================
3. VERIFICATION
========================================================================
To verify the system is running correctly:
1. Backend Health Check:
   GET http://127.0.0.1:8000/api/health
   Response should be: {"status": "healthy", ...}
2. Open http://localhost:3000 in your browser to view the AeroOptima dashboard.
========================================================================
