## 1. What Will Be the Data? (Observation / State Vector)

In Reinforcement Learning for dynamic control, "data" is **not a static dataset or CSV file**. Instead, data is the **live 5-dimensional physical state vector** generated by our simulation environment at every time step $t$ (every 10 seconds of flight):

```python
# State Vector (S_t) fed into the RL Neural Network:
observation = [
    altitude_m,        # 1. Flight Altitude above sea level (0.0 to 12,000.0 m)
    speed_m_s,         # 2. True Airspeed (0.0 to 150.0 m/s)
    battery_soc,       # 3. Battery State of Charge (0.0 to 1.0)
    fuel_remaining_kg, # 4. Fuel remaining in tank (0.0 to 500.0 kg)
    power_required_kw  # 5. Total mechanical shaft power required (0.0 to 500.0 kW)
]
```

---

## 2. How Data Will Be Inserted? (The Simulation Loop)

Data insertion happens in real-time inside a closed-loop execution loop:

```
               CLOSED-LOOP RL DATA INSERTION FLOW
               
 ┌─────────────────────────┐   Observation S_t (5 floats)   ┌─────────────────────────┐
 │ UAV Environment         ├───────────────────────────────►│ Trained RL Model        │
 │ (`environment.py`)      │                                │ (`PPO.predict(obs)`)    │
 └────────────▲────────────┘                                └────────────┬────────────┘
              │                                                          │
              └───────────────── Action: PSR (0.0 to 1.0) ───────────────┘
```

### Python Data Insertion Pipeline:
```python
# 1. Environment generates initial observation S_0
obs, info = env.reset()

while not done:
    # 2. Observation array [alt, speed, soc, fuel, p_req] is inserted into RL Model
    action, _states = rl_model.predict(obs, deterministic=True)
    
    # 3. RL Model returns action array [PSR] (e.g. [0.35])
    # 4. Action is inserted back into the physics environment
    obs, reward, terminated, truncated, info = env.step(action)
    
    done = terminated or truncated
```

---

## 3. What Will Be the Output? (The Action Vector)

The RL Neural Network processes the 5-element state vector and outputs **1 continuous control value**:

$$\text{Action Output } A_t = [\text{Power Split Ratio (PSR)}]$$

Where **PSR** is bounded between **$0.0$** and **$1.0$**:

*   **$\text{PSR} = 0.0$** $\rightarrow$ **100% Turboshaft Engine** (0% Motor). Best for long-distance high-efficiency cruise.
*   **$\text{PSR} = 0.5$** $\rightarrow$ **50% Engine + 50% Electric Motor** (Parallel Hybrid Mode). Used for sustained climb or acceleration.
*   **$\text{PSR} = 1.0$** $\rightarrow$ **0% Engine + 100% Electric Motor** (Pure Electric / Silent Stealth Mode). Used for silent loiter or low-IR overwatch.

## 4. How to Test & Evaluate the RL Model

Testing the RL agent requires comparing its performance directly against the baseline heuristic policy across identical mission profiles.

### Step-by-Step Test Script (`backend/test_rl.py`):

```python
import os
import numpy as np
from stable_baselines3 import PPO
from environment import UAVHybridEnv

def test_and_compare_rl():
    print("=" * 60)
    print("      AeroOptima: RL vs Heuristic Benchmark Test")
    print("=" * 60)

    # 1. Test Baseline Heuristic Policy
    env_heuristic = UAVHybridEnv(
        engine_size_kw=65.0,
        battery_capacity_kwh=20.0,
        use_heuristic_policy=True  # Standard Heuristic
    )
    obs, _ = env_heuristic.reset()
    done = False
    while not done:
        obs, reward, term, trunc, info = env_heuristic.step([0.0])
        done = term or trunc
    
    heuristic_hours = env_heuristic.time_elapsed / 3600.0
    print(f"\n[Baseline Heuristic Policy]")
    print(f"  • Total Endurance : {heuristic_hours:.2f} Hours")
    print(f"  • Ending Fuel     : {env_heuristic.fuel_remaining:.2f} kg")
    print(f"  • Ending SoC      : {env_heuristic.soc * 100:.1f}%")

    # 2. Test Trained RL Policy
    model_path = "backend/rl_model_ppo.zip"
    if not os.path.exists(model_path):
        print("\n❌ RL Model file not found! Train model first using train_rl.py")
        return

    rl_model = PPO.load(model_path, device="cpu")
    env_rl = UAVHybridEnv(
        engine_size_kw=65.0,
        battery_capacity_kwh=20.0,
        use_heuristic_policy=False  # Controlled by RL!
    )
    obs, _ = env_rl.reset()
    done = False
    while not done:
        action, _ = rl_model.predict(obs, deterministic=True)
        obs, reward, term, trunc, info = env_rl.step(action)
        done = term or trunc

    rl_hours = env_rl.time_elapsed / 3600.0
    print(f"\n[Trained RL Policy]")
    print(f"  • Total Endurance : {rl_hours:.2f} Hours")
    print(f"  • Ending Fuel     : {env_rl.fuel_remaining:.2f} kg")
    print(f"  • Ending SoC      : {env_rl.soc * 100:.1f}%")

    # 3. Comparison Summary
    diff = rl_hours - heuristic_hours
    print("\n" + "=" * 60)
    if diff > 0:
        print(f"✅ SUCCESS: RL Policy outperformed Heuristic by +{diff:.2f} Hours!")
    else:
        print(f"📊 COMPARISON: RL Policy achieved {rl_hours:.2f} vs {heuristic_hours:.2f} Hours.")
    print("=" * 60)

if __name__ == "__main__":
    test_and_compare_rl()
```

## 5. Verification Checklist & Success Metrics for Judges

When evaluating the RL test output, look for these 4 key verification indicators:

1. **Zero Stall Events:** Verification that airspeed $V > 1.15 \cdot V_{\text{stall}}$ throughout all phases.
2. **Fuel Economy:** Verification that the engine operates near optimal SFC ($L_f \ge 0.8$) during cruise.
3. **Battery Safety Margin:** Battery SoC never drops below the safety floor ($10\%$ minimum SoC).
4. **Endurance Gain:** RL maximizes total flight time within the 1,000 kg MTOW limit.
