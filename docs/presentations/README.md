# Presentation & Pitch Deliverables

This directory compiles all resources and templates required for the final pitch deck and presentation of the **AeroOptima** Hybrid-Electric UAV Optimizer.

### Contents:
1. **[aerothon_presentation_structure.md](file:///d:/project/HAL/docs/presentations/aerothon_presentation_structure.md)**: A slide-by-slide guide mapping out the logic, design layout suggestions, math equations, and screenshots needed for the presentation.

- **Dashboard Screenshots:** Grab high-resolution screenshots of the UI telemetry matrix, 3D racetrack orbit path, and Plotly.js charts from the running application (`http://localhost:3000`).
- **Weight Fractions Diagram:** Slide 4 features a visual placeholder for the 1,000 kg MTOW component mass breakdown. Use the real-time calculated values from the optimized output.
